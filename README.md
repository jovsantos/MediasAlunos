## Objetivo  
Este projeto foi desenvolvido para aprender e praticar os fundamentos da Programação Orientada a Objetos (POO) utilizando a linguagem C#.
O objetivo é criar um programa em C# que armazene as informações de 3 alunos e exiba seus nomes, notas e médias.

---

## Funcionalidades
✅ Classe **Aluno** com os atributos:
- `Nome`
- `Nota1`
- `Nota2`

✅ Método `void ExibirInformacoes()` para imprimir nome e notas.  
✅ Método `double CalcularMedia()` para retornar a média do aluno.  
✅ Array de **3 alunos** para armazenar e exibir informações.  
✅ Versão inicial com valores pré-definidos e versão final com entrada de dados pelo usuário.

## Como Executar o Projeto

### 1️⃣ Pré-requisitos
- **Visual Studio** instalado  
- **.NET SDK** configurado

### 2️⃣ Passo a Passo
1. **Baixar o projeto**  
   - **Download ZIP**: Clique no botão verde **Code** e selecione *Download ZIP*, depois extraia os arquivos.  
   - **Clonar via Git**:  
     ```bash
     git clone https://github.com/seu-usuario/nome-do-repositorio.git
     ```

2. **Abrir no Visual Studio**  
   - **Arquivo > Abrir > Projeto/Solução**  
   - Localize o arquivo `.sln` ou a pasta do projeto.

3. **Executar o projeto**  
   - Pressione `F5` ou clique em **Iniciar**.
